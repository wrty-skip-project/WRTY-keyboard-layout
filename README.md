# WRTY/HRTY-Layout (Codename: SKIP / SK-Layout)
> **A QWERTY-remembered, single-screen ergonomics keyboard layout for mobile devices. Highly optimized for thumb-typing, featuring central vowel-cross aggregation and prior-art defensive publication.**

---

> **「最初は『WRTY』というロジックの骨格から始まった。けれど、完成したキーボードの上で指を動かしたとき、私の親指は軽快にスキップ（S-K-I-P）していた。だから、コードネームは『すきっぷ配列（SK）』。」**
> 
> **「開発の辿り着いた先に、鉛筆でなぞる感触と、止め跳ね払いのリズム感を再発見した。さらにその運動生理学的な実利を突き詰めた先で、配列は『HRTY』へと進化した。」**
> 
> PCのタイピングは爆速なのに、スマホの50音フリックには脳が馴染まない。かといって、スマホ画面でのQWERTY入力はキーが小さすぎて誤爆だらけ。
> 
> 本システムは、そんな背景を持つ一人の「スマホQWERTY難民」が、親指を自由に「スキップ」させ、その開発の辿り着いた先に、鉛筆で文字をなぞる感覚と止め跳ね払いのリズム感を再発見した、一画面完結型のモバイル・ローマ字入力システムです。
> ユーザーの美学や入力環境に応じて、空間記憶を最優先する「WRTY配列」と、日本語の運指効率を極限まで高める「HRTY配列」の2つのバリエーションを選択できます。

## 🧭 開発コンセプト：QWERTYへの未練と、長文での疲労軽減

本配列の根底にあるのは、QWERTY配列という慣れ親しんだ過去への「断ち切れない未練」です。しかし、それをそのままスマホに持ち込んでも画面の狭さによる破綻でした。
そこで、PCネイティブとしての「空間記憶」を肯定しながら、スマートフォンが持つ「身体性」を融合させ、長文を打つ際の親指の負担軽減と、アナログな筆記の快感へと昇華させるアプローチをとりました。

*   **親指の可動域を半径1.5cm圏内に固定**：文字盤の端から端へ指を大きく往復させる必要がなくなるため、長文入力時の手の疲労感が軽減されます。
*   **「記号・数字のモード切り替え」を排除**：記号画面やテンキー画面を連打して往復するロスを排除。入力中の画面のチラつき（視覚的ノイズ）をなくし、フリック時の認知疲労を抑えます。

## 🛠️ 本システムを構成する 6つの方針

### 1️⃣ 子音配列に詰め込んだ「QWERTYへの未練」と空間記憶（選べる2つのアイデンティティ）
アルファベットの配置は、ユーザーが長年PCで培ってきたQWERTY配列の空間認知をそのまま引き継いでいます。ユーザーのタイピングスタイルに応じて、2つのプリセットを使い分ける機能の棲み分けが成立しています。
*   **WRTY配列（空間記憶優先・論理の美学）**：最上段左側にそのまま `W・R・T・Y` を残すことで、PCネイティブの脳内メモリと100%完全シンクロ。移行時の学習コストを最小化します。
*   **HRTY配列（日本語効率優先・身体のリアリズム）**：最上段を `H・R・T・Y` へと変更し、日本語のローマ字入力で頻出する `H` を一等地へ配置。さらに下段へと降りた `W` が隔離配置 `Q` と近接することで、縦横の物理移動量および疲労スコアを極限まで引き算します。
*   共通ラインとして、中段に `S・K`、下段に `C・N・M` を残すことで、直感的な空間認知を維持しています。

### 2️⃣ 母音の十字集約 ＝ 「あ行フリック」の流用による離散ストレスの排除
合計6列（文字4列＋特殊2列）のちょうど中央、2.1マス分（横幅 約24.3mm）という圧倒的な専有面積を誇る特大キーに `A` を配し、左に `I`、上に `U`、右に `E`、下に `O` を十字フリックで割り当てています。
5x4のかなフリックのホームポジション（た行）が常に外周へ指を離散させ続けるのに対し、本作は全打鍵の約73%〜76%をこの中央の広大なセーフティゾーンとその至近圏内だけに集約。QWERTYの記憶で子音を叩いた後、母音の処理だけは親指が最もリラックスできる中央ホームへ引き戻され、スマホの記憶をそのまま活かして**スライド入力**を行います。

### 3️⃣ 連母音（ou / ei）に宿る「止め跳ね払い」のリズム
**漢語由来の日本語（音読み）**の構造上、最頻出する2つの連母音（子音＋ou / 子音＋ei）において、指先がリズミカルな往復運動をするのは、設計の辿り着いた先で再発見したセレンディピティです。
*   **「〜おう（ou）」**：中央キーの垂直線上（下➡️上）の一直線なピストン運動へ変化。下にグッと引いて止めた勢いのまま、上へと鮮やかに「跳ね上げる」運指になります。
*   **「〜えい（ei）」**：水平線上（右➡️左）の滑らかなワイパー運動へ変化。親指の付け根を軸とした自然な扇形の旋回運動にシンクロし、美しい「はらい（払い）」の軌跡を描きます。
指に急ブレーキをかけることなく、運動エネルギーをそのまま反転させて**「2ストローク」**で処理できるため、タイピングが心地よい鉛筆のステップへと変わります。

### 4️⃣ 促音（っ）連打のための「P」独立配置
**漢語由来の日本語**や「カタカナ外来語」の音声構造を分析した、身体性への妥協です。
*   外来語で頻出する「〜ップ（アップ、コップ、タップ等）」の促音便において、同じキーの2回フリックは指にとって大きな負担です。
*   あえて統計データを無視し、`P` を独立1キー（タップで発動）として常駐させることで、PCと同じ「親指でポンポンと2回タップ（連打）するだけで『っ』が仕込める」肉体的快感を獲得しました。空間配置もQWERTYの「右手小指の記憶」を継承しています。

### 5️⃣ 言語学に基づく「硬口蓋音の立体収納」と『隔離配置』によるショートカット
日本語において極めて必要度の低い `C`, `X`, `Q` の3文字は、一等地から移動して、最下段左端の1キーへ**「隔離配置」しました。**
*   しかし単に除けただけでなく、音声学においてこの3文字は「同じ舌のフォームで作られる音（硬口蓋音）」のグループであるという裏付けを利用し、`C` の上下フリックに `X` と `Q` を格納。音韻論的スッキリ収納を実現しています。
*   ※特にHRTY配列においては、この最下段左端に隔離された `Q` から、下段へ降りてきた `W` への縦の繋ぎがわずか1行分（11.2mm）に短縮される設計となっています。

### 6️⃣ 記号モードを終わらせる「`R`上フリック（`•`）× 予測変換」ハック
キーボード内に無数の特殊記号を物理ボタンとして詰め込む力技を完全に排し、`R` の上フリックに万能のトリガーキー「`•`（中黒）」を1つだけ配置しました。
*   **「`•` を出す ➡️ 予測変換バーに並んだユーザ辞書の記号を直接タップする」**
*   [iOSの「azooKey」](https://azookey.com)や[Androidの「スミレ」](https://github.com)の予測変換機能を活用した、変換操作すら挟まない超高速の2ステップ入力です。キーボードの画面を1ミリも切り替えることなく、登録したあらゆる特殊記号（％やカッコなど）を瞬時に呼び出すことができます。
